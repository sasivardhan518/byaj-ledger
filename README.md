# Byaj Ledger

Indian bank-style interest calculator for FDs, RDs and savings accounts, with a quarterly tax and advance tax view. Data can be saved to a private app folder in your own Google Drive.

**Live page:** https://sasivardhan518.github.io/byaj-ledger/

Change `interest-calculator.html` and push to `main`. GitHub Actions builds the page and deploys it. Google setup is in [site/SETUP.md](site/SETUP.md).

Figures are planning estimates, not tax advice.
